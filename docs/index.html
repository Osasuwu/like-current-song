Like Current Song

Like the song you are hearing without unlocking your phone.

Home Privacy Terms Source

Like Current Song is a free and open-source project in two halves. On Android it watches for a media-button pattern — a quick pause-play on your headphones, for example — and saves whatever is playing to your library. On Windows a small desktop tool does the same from a tray icon and a global hotkey; on macOS and Linux it currently ships as a one-shot command you run yourself, like-current-song like-once.

It works with Spotify and YouTube Music. Optional extras can also remove the song from an archive playlist, add it to a best playlist, and follow the artist.

Get it

There is no app-store listing. Everything lives on GitHub, and you build or install it yourself:

  • Source code and build instructions
  • Setup guide — connecting Spotify or YouTube Music
  • Issue tracker — bugs and feature requests

Bring your own credentials

The project does not ship shared API keys. Both Spotify and Google require each person to register their own application, so the setup guide walks you through creating one and pasting the client ID into the app. Those credentials stay on your device.
